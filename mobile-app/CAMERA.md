# ESP32-CAM камер холбох

1. `firmware/src/main.cpp` доторх `ssid`, `password`-ийг Wi-Fi сүлжээндээ тааруулж firmware-ийг ESP32-CAM дээр суулгана.
2. Утсаа ижил Wi-Fi сүлжээнд холбоно. Serial Monitor-ийг 115200 baud-аар нээж `Stream URL: http://.../stream` хаягийг авна.
3. Аппын камерын талбарт тэр URL эсвэл IP хаягийг оруулаад **Камер асаах** товч дарна. Одоогийн firmware порт 80 ашиглана; өөр firmware бол `http://IP:81/stream` зэрэг бүтэн URL оруулж болно.
4. **Камер зогсоох** товч дүрсний холболтыг хаана. Апп background руу ороход мөн зогсоно.

Камерын дүрс болон илрүүлэлтийн мэдээлэл хоёулаа Wi-Fi-аар дамжина. **Камер асаах** үед апп тухайн IP-ийн `http://IP:81/status` хаягаас мэдээллийг 500 миллисекундын зайтай авна. Камерын `/stream` сервер порт 80, мэдээллийн сервер порт 81 ашиглана. Bluetooth холбох шаардлагагүй.

Илэрц өөрчлөгдөхөд апп дэлгэцээ шинэчилж, дуугаар хэлнэ. Холболт тасарвал хуучин илэрцийг арилгаж, дахин холбогдохыг оролдоно. Камер зогсоох болон апп background руу ороход мэдээлэл авах нь мөн зогсоно.

Шалгах: камерын stream ажиллаж байхад browser дээр `http://IP:81/status` нээхэд `{"decision":"CLEAR"}` зэрэг JSON хариу ирнэ. Апп дээр **Wi-Fi-аар холбогдсон** гэсэн төлөв харагдах ёстой.

## Урд саадын анхааруулга

HC-SR04-ийн Trig нь GPIO13, Echo нь GPIO12 тохиргоотой. Мэдрэгч урд зүг рүү харсан байна. 150 см хүртэл зайтай хоёр дараалсан хэмжилтэд саадын анхааруулга өгнө; 50 см буюу түүнээс ойр хэмжилтэд шууд анхааруулна. 150 см-ээс хол хоёр хэмжилтийн дараа саадын төлвийг суллана. Хэмжилт байхгүй эсвэл хүчингүй бол `UNKNOWN` төлөвтэй, зай `null` байна.

`/status` нь `decision`, `distance_cm`, `age_ms` өгнө. 1.5 секундээс хуучирсан хэмжилтийг ашиглахгүй. 150 см дотор орж ирэхэд нэг удаа зайг хэлнэ. Дотор нь хэвээр байхад зай өөрчлөгдсөн ч давтаж хэлэхгүй. 150 см-ээс хол үед зайны анхааруулга өгөхгүй. Гадна нь 1.5 секунд тогтвортой байсны дараа дахин дотогш орвол шинэ анхааруулга өгнө. Утсанд Монгол TTS хоолой байвал ашиглана, байхгүй бол апп доторх Монгол аудиогоор анхааруулна; англи хоолой руу шилжихгүй. Нүх, шат, зам хөндлөн гарах аюулгүй байдлыг энэ хэмжилт тогтоохгүй.

Ширээн дээр шалгахдаа мэдрэгчийн урд 100 см, 40 см зайд хавтгай зүйл барьж, `/status` болон аппын дууг шалгана. Хэмжилт тасрахад `CLEAR` гэж мэдээлэх ёсгүй.

## iPhone дээрх офлайн AI

`modules/ai-vision` нь Apple Vision/Core ML ашигладаг local Expo module. YOLOv3 Tiny Int8 загвар апп дотор багтана. Native модуль нэмэгдсэн тул өмнөх development build-ийг шинэ build-ээр солих шаардлагатай; Metro reload дангаараа хангалтгүй.

Камер асахад `/capture`-аас JPEG авч iPhone дээр объект танина. Энэ нь HC-SR04-ийн хэмжилтээс хамаарахгүй. Төв хэсэгт байгаа, 55%-аас дээш confidence-тэй, хоёр дараалсан кадрт танигдсан объектыг нэрлэнэ. Зураг/AI хариу тасарвал хуучин танилтыг арилгана. Мэдрэгчийн ойрын саадын анхааруулгыг AI үл таньсан ч өгнө. Объектын нэр болон хэт авианы хэмжсэн зай нь тусдаа ажиглалт юм.

Бүх танилт локал; зураг cloud руу илгээхгүй. iPhone, ESP32-CAM хооронд Wi-Fi холболт шаардлагатай, интернэт шаардлагагүй. Mac/Metro-гүй ашиглахдаа JavaScript багцтай Release build суулгана. Бэлэн загварын бүх объектын ангилал нь бүх төрлийн саадыг хамарна гэсэн үг биш. Нүх, шат, аюулгүй гарц, гэрлэн дохионы төлөвийг энэ загвар тогтоохгүй.

Тест: `node --experimental-strip-types --test tests/vision.test.mjs`, `npx tsc --noEmit`, `npm run lint`. Native загварын эх сурвалж болон checksum: `modules/ai-vision/MODEL.md`.

## Монгол анхааруулгын дуу

`AiVisionAudio.bundle` дотор 2–400 см-ийн зай, объектын Монгол нэр, яаралтай болон алдааны анхааруулгын AAC аудио багтана. Монгол системийн хоолой байхгүй iPhone ч интернэтгүй дуугарна. Энэ нь дурын текст уншдаг ерөнхий TTS биш, аппын хязгаарлагдмал анхааруулгын үгсийн сан юм. Хоолойн эх загвар, лиценз, үүсгэх заавар: `modules/ai-vision/ios/Audio/README.md`.

Аудиог шалгах тест: `node --experimental-strip-types --test tests/mongolianAudio.test.mjs`. Яаралтай зогсох клип эхэнд тоглоно; объектын нэр ба мэдрэгчийн зайг тусдаа өгүүлбэрээр хэлнэ. Нэг анхааруулга дуусаагүй байхад энгийн давталтыг давхарлуулахгүй.

## Аппыг дахин build хийх

HTTP болон iOS local network тохиргоо өөрчлөгдсөн тул native development build-ийг дахин үүсгэж утсандаа суулгана. Зөвхөн Metro reload хангалтгүй. Одоо байгаа BLE сан Expo Go-д ажиллахгүй.

```sh
cd mobile-app
npx expo run:android
# эсвэл macOS дээр iPhone build:
npx expo run:ios --device
```

iPhone дээр local network зөвшөөрлийг олгоно. Дүрс ирэхгүй бол утасны browser-оор stream URL-аа шалгаж, ESP32-ийн тэжээл, Wi-Fi, IP хаягийг нягтална. Router-ийн client isolation нь төхөөрөмжүүдийн хоорондын холболтыг хааж болно. Эхний шалгалтад тусдаа Wi-Fi router ашиглах нь тохиромжтой.
